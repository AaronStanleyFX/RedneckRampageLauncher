## Redneck Rampage Launcher v1.0.0 — HD launcher + in-game trainer

Play the **GOG Redneck Rampage Collection** natively on Windows 10/11 with the modern **Raze** engine. You don't need DOSBox.

### ✨ Highlights
- 🎮 **3 games in one launcher**: Redneck Rampage, Suckin' Grits on Route 66, Rides Again
- ⚙️ **Raze engine downloaded automatically** on first launch
- 🎵 **Original CD soundtrack** extracted from the GOG CD images and played in game
- 🖥️ **HD / 4K upscale**, fullscreen, V-Sync, FPS limit, OpenGL / Vulkan
- ⌨️ Custom keys (AZERTY & QWERTY), mouse options, auto-run, crosshair, FPS counter, "No monsters" mode

### 🛠️ New: in-game trainer
Press **Esc → Trainer** during a game to toggle each option ON/OFF at any time:

| Option | Key |
|---|---|
| Infinite Health | `H` |
| Infinite Ammo | `J` |
| Infinite Inventory | `K` |
| Fly Mode (jump to take off, look up/down while moving) | `L` |
| No Clip | `N` |
| Remove Enemies | `U` |
| Erase Buildings (reload the level to restore) | `O` |

### 📦 Installation
1. Download **`Redneck-Rampage-Launcher-v1.0.0.zip`** below.
2. Extract it **into your Redneck Rampage Collection folder** (the one that contains `REDNECK.GRP`).
3. Run **`Redneck Rampage Launcher.exe`**. If SmartScreen shows a warning, choose *More info → Run anyway*, or use `Redneck Rampage Launcher.cmd`.
4. Accept the Raze download on first launch (about 20 MB).

### ⚠️ Notes
- **No game data is included.** You need your own copy of Redneck Rampage Collection (GOG).
- The trainer doesn't work at the highest difficulty, because the game blocks cheats there.
- Optional: add your own `Launcher\background.jpg` and `Launcher\music.mp3` to customize the launcher.
